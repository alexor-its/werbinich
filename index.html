Aktuelle Referenzen

Nach 26 Jahren bei Microsoft, in denen ich die Hybrid Cloud von Azure mitgestaltet habe, will ich jetzt dorthin, wo diese Technologie wirklich ankommt: zu den Kunden und ihren Herausforderungen.

Kunde der öffentlichen Hand, seit Ende 2025

Hybride Modernisierung des Rechenzentrums

AusgangssituationDer Kunde betreibt seine Server-Infrastruktur (300+ Server) auf Azure Local und wollte den bisherigen, auf WSUS und SCVMM basierenden Patch-Prozess ablösen sowie seine Terminal-Server-Landschaft (ca. 1.500 gleichzeitige Benutzer) modernisieren. Für das weitere Server-Management ist die System-Center-Suite im Einsatz.
VorgehensweiseIch konzipierte und implementierte ein zentrales, cloudbasiertes Patch-Management über Azure Arc und den Azure Update Manager inklusive Onboarding der Hyper-V-Cluster und VMs, Inventory, Policies, Monitoring, Alerting und Microsoft Defender for Cloud. Darauf aufbauend leitete ich einen Proof of Concept für Azure Virtual Desktop (AVD) auf Azure Local mit Windows 11 Multi-Session in einer Private-Networking-Architektur. Infrastructure as Code auf Basis von PowerShell, Azure CLI und ARM, AI-assisted entwickelt, ist dabei ein Erfolgsfaktor.
ErgebnisDer Proof of Concept wurde erfolgreich abgeschlossen. Der Kunde entschied sich für die Produktivsetzung von AVD als Ersatz der Remote-Desktop-Umgebung und beauftragte mich mit der weiteren Umsetzung und Betriebsbegleitung. Ergänzend verantworte ich ein automatisiertes Framework zur Überführung von über 300 VMs auf Azure Local; die Produktivsetzung von AVD ist bis April 2027 geplant.

EU-Kunde (Bulgarien), Greenfield

Eigene Azure-Location im Rechenzentrum

AusgangslageDer Kunde wollte eine eigene Azure-Location im Rechenzentrum aufbauen, um Virtualisierung, Container, Workplace und KI-Workloads auf einer einheitlichen, souveränen Plattform zu betreiben.
VorgehensweiseAngefangen beim Angebot verantwortete ich als Cloud Solution Architect den Greenfield-Aufbau einer Sechs-Knoten-Plattform auf Azure Local: vom Netzwerkdesign und der Hardware-Spezifikation über die Azure-Integration bis zum vollständig skriptgesteuerten Deployment mit PowerShell und Azure CLI.
ErgebnisDie Plattform wurde mit Ausfall- und Leistungstests validiert, inklusive Betriebsdokumentation übergeben und das Kundenteam für den Eigenbetrieb befähigt. Der Kunde hat damit eine hybride Basis, die er selbst weiterentwickeln kann. Ein Folgeprojekt zur Einführung von KI-Szenarien mit Azure AI Foundry auf Azure Local ist in Vorbereitung.
